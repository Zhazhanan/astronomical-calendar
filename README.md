# 日—地—月与中国历法（离线教学页）

这是一个可直接在本机打开的中文天文学习页面。它把太阳中心与地球中心两个视角放在同一时刻下展示，用来观察地球公转、自转、二十四节气、农历、月相、干支年与当地日照之间的联系。

## 打开方式

直接双击 [tiangan_dizhi_offline.html](./tiangan_dizhi_offline.html)，或在文件管理器中用浏览器打开即可。页面不依赖服务器，支持 `file://` 直接运行；所需的脚本、月历库和可选数据都随项目保存。

默认观察条件为：

- 时区：上海（`Asia/Shanghai`）；
- 地点：北京（北纬 39.9042°、东经 116.4074°）；
- 当前日期时间：打开页面时的当前时刻。

## 怎样使用

### 控制时间和地点

顶部可直接输入日期与时间，也可使用“前一天”“今天”“后一天”。播放按钮按所选速度推进时间，提供三档：1 天/秒、7 天/秒、30 天/秒。

地点可切换北京、上海、广州，或选“自定义地点”后输入经纬度。时区默认上海，也可使用浏览器本地时区；读数会同时给出本地时间与 UTC，便于理解同一瞬间的不同表达。

### 看两个视角

- 太阳中心视角：观察地球绕太阳的年运动、黄道、地轴方向、月球轨道倾角与轨道交点。
- 地球中心视角：观察太阳黄经、二十四节气、月球黄纬、月相和交点之间的关系。

桌面宽屏会并列显示两个视角；中等宽度上下排列；手机上用“太阳中心视角 / 地球中心视角”按钮切换。场景可拖动旋转，提供重置两个视角按钮。导出的 PNG 只含三维场景，不包含叠加文字标签。

### 全年时间轴与学习卡片

全年时间轴把公历、二十四节气、农历放在同一条按真实 UTC 时间比例绘制的轴上。可用时间轴下方的范围滑块浏览日期；方向键前后移动一天，Page 键前后移动七天，Home/End 跳到年初/年末。节气名称可以获得键盘焦点并显示对应时刻。

六张“从图中学习”卡片从同一个天文时刻读取数据。干支卡片支持查询 1900–2100 年，分别展示以春节与立春为年界的两种常见干支年口径。

## 3D 不可用时

如果浏览器无法创建 WebGL 场景，页面仍会保留日期、时区、地点、当前读数、全年时间轴和学习卡片，并显示一个二维日地月示意图。可使用“重试 3D”重新尝试创建三维场景；这不会联网，也不会丢失当前学习时刻。

## 可选本地星表 CSV

“进阶天文”中的星表只在本机读取，不上传、不联网。单个文件上限为 **2 MB**，最多读取 **10,000** 条数据行。

CSV 需包含下列任一种表头组合：

- `ra_deg,dec_deg`：赤经直接以度填写，RA 范围 0–360；
- `ra,dec`：需在页面选择 RA 单位为“度（0–360）”或“时（0–24）”。

可选列为 `name`、`magnitude`。赤纬范围为 −90 至 90；格式或范围不正确的行会跳过，表头不符合要求会给出本地错误提示。

“银河示意”和“二十八宿”均是用于方位与文化学习的图层；其中二十八宿是传统星官的**示意**，不应当作精确星图。

## 教学模型与精度

本页的目标是把同一时刻的几何关系、历法读数和观察者读数连起来，采用的是适合教学和交互展示的近似模型，而不是天文历或导航软件。

- 农历转换、干支年和相关提示只在当地年份 1900–2100 范围内提供；超出范围会提示，不外推结果。
- 节气与月相的页面验证矩阵使用计算容忍范围：节气求解容忍 1 秒，朔望弦求解容忍 1 分钟；这些是内部教学模型的数值判定阈值，不表示与专业星历的保证误差。
- 轨道、月球倾角、相位、太阳黄经、地平高度和昼长用于解释趋势与相对关系。它们不应用于导航，也不能用来预报日食或月食。
- 页面代码和自动化单元测试会检查上述数据链路、离线资源与静态结构；本说明**不声称已经在所有浏览器或设备中完成视觉验收**。不同浏览器的 WebGL 能力、字体和时区数据仍应在实际设备上确认。

## 离线与可访问性

页面不在运行时请求网络资源。控件有可读名称，焦点样式清晰，移动端控件保持至少 44px 的触控高度；系统启用“减少动态效果”时会关闭 CSS 动画与过渡。状态提示区使用单一礼貌播报区域，避免重复播报。

## 验证

项目包含 Node 单元测试与 Python 页面静态检查。修改后可运行：

```sh
node --test tests/*.test.cjs
python3 -m unittest discover -s tests -p 'test_*.py'
```

静态检查验证离线资源、唯一 ID、标题层级、控件标签、时间轴范围控件、减少动态效果和页面状态区等结构性要求。它不能替代真实浏览器中的视觉、键盘与屏幕阅读器测试。
